# ITA Wellness Financial Model

Interactive financial model for an Italian wellness retreat concept, built with React and Recharts.

## Features

- **Interactive Tabs**: Executive Summary, Investment, Projections, Returns, Scenarios, Risks, Grants, Assumptions
- **Scenario Analysis**: Conservative, Base Case, and Optimistic projections
- **Dynamic Calculations**: Real-time financial modeling
- **Visual Analytics**: Charts and tables
- **Professional Design**: Dark theme optimized for presentations

## Quick Start

### Prerequisites
- Node.js (v14+)
- npm or yarn

### Installation

```bash
git clone https://github.com/zalart-pixel/ita-wellness-model.git
cd ita-wellness-model
npm install
```

### Run Locally

```bash
npm run dev
```

App runs at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

## Technologies

- React 18
- Vite
- Recharts
- CSS-in-JS

## Key Model Assumptions

- Investment: 2.6M EUR
- Property: 10 rooms, 300 sqm
- Operating: 32 weeks/year
- Base AWR: 5,650 EUR/week
- Year 1 Occupancy: 45% (ramping to 75%)
- Projected IRR: 18-22% (base case)
- Projected MOIC: 2.2-2.8x

## Deployment

```bash
npm run build
npm run deploy  # Deploy to GitHub Pages
```
